## 4. หมายเหตุสำหรับตอนลงมือทำ

- **วิธีคิดมูลค่า:** ราคารับเข้าล่าสุดของแต่ละวัสดุ (`stock_transaction_items.unit_price` ของรายการ IN ล่าสุดที่มีราคา) × คงเหลือ วัสดุที่ไม่เคยมีราคาจะนับเป็น 0 และควรแสดงจำนวนรายการที่ไม่มีราคาให้เห็น
- **สิทธิ์:** มูลค่า (บาท) เห็นเฉพาะ ADMIN และ STAFF เหมือน Dashboard เดิม ⏳ ยืนยันว่า STAFF ควรเห็นมูลค่าไหม
- **กราฟ (ข้อ 3, 5):** ทำด้วย CSS แบบการ์ด "เบิกมากที่สุด" โดยไม่ต้องเพิ่ม chart library ตามกติกาใน CLAUDE.md ถ้าต้องการกราฟเส้นต้องตกลงเรื่อง library ก่อน
- **การ์ดใหม่:** ใช้กรอบสูงคงที่และเลื่อนภายในได้ แบบเดียวกับการ์ดที่มีอยู่
- **API:** เพิ่ม endpoint ใต้ `/dashboard/*` (ADMIN, STAFF) และเพิ่ม model ใน `frontend/src/app/shared/models/dashboard.ts` ตามกติกา API contract
